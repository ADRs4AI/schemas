schemas.adrs.systems

The machine-readable home of the ADRs for AI methodology — teaching bundles a model can fetch whole.

Each released version of the canonical human-AI collaboration template is concatenated into one fetchable markdown file (fence-collision-safe by proof, not by hope), so a model that meets any single file of the methodology can recover the full context in one request.

  • /llms.txt — the model-native index: what exists, where, how to cite it
  • /v1/template/latest/ — the newest released template, bundled (the two-pointer philosophy: latest moves, pinned versions never do)
  • /v1/template/v3.12.1/ — pinned (immutable)
  • /v1/template/v3.12.0/ — pinned (immutable)
  • /v1/template/v3.11.6/ — pinned (immutable)

For humans: the story lives at adrs.systems; the deliberation records behind every design decision are public in the repos themselves. Cite the living work by its concept DOI 10.5281/zenodo.23303469.
